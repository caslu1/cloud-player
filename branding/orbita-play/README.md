# Orbita Play – logo

Símbolo: planeta em órbita cortado por um rastro (inspirado no logo "Orbita"), com a palavra **ORBITA** em Outfit Regular e **PLAY** em Outfit Bold, na cor de destaque `#6CD4FF`. Fundo escuro: `#0B1020`.

| Arquivo | Uso |
|---|---|
| `orbita-play-logo.svg` / `.png` | Horizontal, fundo transparente (para fundo escuro) |
| `orbita-play-logo-dark-bg.svg` / `.png` | Horizontal com fundo azul-escuro |
| `orbita-play-logo-light.svg` | Horizontal para fundo claro |
| `orbita-play-logo-stacked.svg` / `.png` | Vertical (símbolo em cima, texto embaixo) |
| `orbita-play-mark.svg` | Só o símbolo, branco |
| `orbita-play-app-icon.svg` / `.png` | Ícone de app 512×512 |

O texto já está convertido em curvas, então os SVGs abrem iguais em qualquer lugar. Para mudar cores ou tamanhos, edite `generate.py` e rode `python3 generate.py` (requer `pip install fonttools`).
